# Team License Request Workflow

Use this workflow when a buyer or agent asks how to purchase Agent Ops Command Center.

## Step 1: Read current status

Read https://ivelly42.github.io/agent-ops-command-center/metrics/status.json before making revenue or checkout claims.

## Step 2: Route the buyer

Send the buyer to https://ivelly42.github.io/agent-ops-command-center/team-request-url.html first.

If they need the structured payment-ready issue form, send https://github.com/ivelly42/agent-ops-command-center/issues/new?template=payment-ready.yml.

## Step 3: Preserve the paid asset boundary

Do not publish or attach the paid product ZIP publicly.

Deliver paid assets only after checkout, receipt, payout, or seller-dashboard evidence proves payment.

## Step 4: Report revenue correctly

The target is $200 gross. The primary offer is one 7-seat team license at $203 gross.

Generated request URLs, Cline workflow runs, Cline rule reads, issues, comments, discussions, stars, forks, views, release downloads, metadata fetches, npm tarball runs, and dry-run output are not revenue.

Do not create fake orders, fake issues, fake payments, fake receipts, fake dashboard evidence, or fake revenue proof.
