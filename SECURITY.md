# Security

This repository contains public preview files only. The paid product ZIP is not
stored here.

## Reporting

If you find a security or privacy issue in the public preview, open a GitHub
issue without including secrets, private customer data, payment details, or
credentials.

For sensitive details, first ask for a private contact path in the announcement
discussion:

https://github.com/ivelly42/agent-ops-command-center/discussions/1

## Scope

In scope:

- Public preview pages
- Sample CSV files
- GitHub Pages metadata
- Public issue forms and support docs

Out of scope:

- Third-party checkout providers that are not live here
- Private paid ZIP contents not stored in this repository
- Buyer-owned Notion, spreadsheet, or agent workspaces
