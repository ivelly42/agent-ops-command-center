## Fit Check

| Signal | Good fit | Poor fit |
| --- | --- | --- |
| Agent use | Multiple meaningful agent runs per week | Rare agent use |
| Verification pain | Work is hard to prove after chat ends | Current proof system works |
| Handoff pain | Work crosses sessions, tools, or reviewers | One short session covers the work |
| Launch work | Needs revenue proof and delivery records | No product or launch workflow |
| Break-even | One avoided cleanup hour is worth `$29` | Cleanup cost is lower than the pack |
