What A Run Log Captures

Use these fields before, during, and after an agent changes code, docs, launch surfaces, or paid delivery artifacts.

Objective

Record the task, acceptance condition, stop rule, and why the run matters.

Scope

Keep allowed files, blocked paths, changed files, and reviewer boundaries in one row.

Verification

Store exact commands, rendered URLs, screenshots, release digests, or review evidence.

Cost Notes

Compare tool spend, cleanup time, repeated failures, and avoided manual rework.

Failure Signals

Capture drift, missing tests, stale assumptions, weak proof, and prevention notes.

Handoff

Preserve current state, unresolved blockers, next action, and owner before context resets.
