# Agent Ops Command Center Preview

Run AI coding agents with evidence.

Most builders using Codex, Claude Code, Cursor, or local agents have the same problem: the work disappears into chat history. You remember that an agent fixed something, but not which prompt worked, which command passed, which file changed, or why a failure happened twice.

Agent Ops Command Center gives you a lightweight operating system for that.

## What You Track

- Agent registry: each agent, model, tool set, best use, and avoid list.
- Run log: objective, inputs, output, files changed, verification, result, follow-up.
- Prompt library: prompt versions, change reason, known failure, eval score.
- Verification ledger: exact command or proof required before calling work done.
- Cost tracker: estimated tokens, cost, human time saved, ROI notes.
- Failure modes: symptom, root cause, fix, and prevention rule.

## Why It Works

The template forces every agent run into three facts:

1. What was the objective?
2. What evidence proves the result?
3. What lesson prevents repeat failure?

That is enough structure to reduce repeated mistakes without turning your workflow into project-management theater.
