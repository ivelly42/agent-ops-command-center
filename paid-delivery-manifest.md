## Delivery Proof

The seller should record:

- ZIP filename;
- ZIP SHA256 digest;
- archive test result;
- delivery method;
- delivery timestamp;
- buyer acknowledgement.

## Revenue Rule

Count revenue only when checkout, receipt, payout, or seller-dashboard evidence exists.

Do not count GitHub issues, release downloads, stars, Gist views, comments, Hugging Face likes, or private intent as revenue.
