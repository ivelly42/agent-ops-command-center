# Contributing

This repository is the public launch and preview surface for Agent Ops Command
Center. Contributions should improve the public preview, buyer clarity, or
verification quality without exposing the paid ZIP.

## Good Contributions

- Fix unclear copy in public preview pages.
- Add missing links between public templates.
- Improve sample CSV clarity.
- Report broken links, sitemap issues, or preview release problems.
- Suggest buyer objections that should be answered in public docs.

## Out of Scope

- Do not publish the paid product ZIP.
- Do not add paid-pack-only files to this repository.
- Do not count issue requests, comments, stars, or downloads as paid revenue.
- Do not add spammy outreach, scraped contact lists, or unrelated directory
  submissions.

## Revenue Evidence Rule

Revenue is proven only by checkout, receipt, seller dashboard, or payment
processor evidence. Purchase-intent issues are useful demand signals, but they
are not revenue.
