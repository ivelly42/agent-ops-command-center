## Checkout Readiness Checklist

| Gate | Pass signal |
| --- | --- |
| Checkout URL | Live payment page works for a buyer |
| Receipt or order ID | Each buyer has a unique paid record |
| ZIP digest | Paid archive has a recorded SHA256 |
| Archive test | ZIP passes extraction test |
| Delivery manifest | Buyer delivery row is filled before sending |
| Revenue proof | Gross revenue uses only payment evidence |
| Buyer acknowledgement | Buyer confirms delivery or access path |

## Revenue Rule

Do not count GitHub issues, release downloads, stars, comments, Gist views, or private intent as paid revenue.

Count revenue only when checkout, receipt, payout, or seller-dashboard evidence proves payment.
